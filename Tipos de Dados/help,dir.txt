dir

Retorna a lista de nomes no escopo atual ;
Com um argumento, retorna uma lista de atributos válidos para o objeto ;
(Métodos) .

dir ()
dir (100)

help

Invoca o sistema de ajuda integrado ;
É possível fazer buscas em modo interativo ;
ou informar por parâmetro qual o nome do módulo, função, classe, método ou variável.

help ()
help (100)

help (str)
help (float)

etc.
